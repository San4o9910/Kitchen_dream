# Kitchen Dream OS — App Architecture v0.1

## Core modules

- Dashboard
- Meal Planner
- Recipes
- Freezer Inventory
- Preparation Day
- Shopping List

## User flow

Purchase -> Preparation -> Vacuum packages -> Storage -> Meal selection -> Cooking

## Main entities

Recipe connects with:
- ingredients
- preparation batch
- freezer items
- calendar meals

## UI principles

- mobile first
- large visual cards
- minimal text while cooking
- status colors
- offline friendly
