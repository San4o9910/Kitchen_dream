# Kitchen Dream OS — Preparation Day Workflow v1.0

## Goal
One preparation day transforms purchased products into organized vacuum packages and freezer inventory.

## Flow

1. Purchase products
2. Clean and portion ingredients
3. Create semi-finished products
4. Vacuum seal
5. Label packages
6. Register in freezer inventory

## Production sequence

### Stage 1 — Meat preparation
- Portion chicken
- Prepare minced meat
- Cut pork

### Stage 2 — Semi-finished production
- Chicken cutlets
- Meatballs
- Meat bases for sauces
- Vegetable mixes

### Stage 3 — Packaging
Every package receives:
- ID
- Name
- Date
- Quantity
- Related recipe
- Storage location

## Example label

FREEZER-001
Chicken cutlets
4 portions
Recipe: chicken_cutlets
Created: YYYY-MM-DD

## Kitchen rule
Freeze components whenever possible. Prepare fresh only what loses quality after freezing (fresh salads, some garnishes).
