# Kitchen Dream OS — UI Architecture v0.1

## Product direction

Kitchen Dream OS is a family food operating system built around batch cooking, vacuum preparation and freezer management.

## Main navigation

- Dashboard
- Meal Calendar
- Freezer
- Preparation Day
- Recipes
- Shopping

## Dashboard

Shows:
- today's meal
- required freezer item
- preparation reminders
- freezer status
- shopping status

## Visual language

Style: Warm Minimal Kitchen

Principles:
- large cards
- simple icons
- clear statuses
- mobile-first layout

Status colors:

🟢 Ready
🔵 Frozen storage
🟠 Cooking required
🔴 Attention

## Core user flow

Ingredients -> Preparation -> Vacuum Pack -> Storage -> Meal -> Cooking
