# Kitchen Dream OS — UI Screens v1.0

## Navigation

- Home Dashboard
- Meal Calendar
- Freezer
- Preparation Day
- Recipes
- Shopping

## Dashboard

Shows:
- today's meal
- packages to take out
- freezer status
- next preparation day

## Freezer Screen

Card based inventory:

Package
- name
- quantity
- date
- status
- recipe link

## Recipe Card

Contains:
- ingredients
- semi-finished preparation
- cooking steps
- storage rules
- cost

## Preparation Screen

Production checklist:

Prepare → Vacuum → Label → Store

Design direction:
Warm minimal kitchen style. Large cards, simple icons, clear status colors.
