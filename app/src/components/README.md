# Components

Planned reusable UI components:

## RecipeCard
Displays:
- dish name
- ingredients
- preparation package
- cooking steps

## FreezerCard
Displays:
- package name
- quantity
- storage status
- linked recipe

## PreparationStep
Displays:
- task
- status
- completion progress

## MealCard
Displays:
- date
- meal type
- required freezer item
