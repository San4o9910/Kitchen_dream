# Kitchen Dream Dashboard UI v0.1

## Purpose
Главный экран управления семейной кухней.

## Blocks

### Today Meal
- блюдо дня
- время приготовления
- связанные заготовки

### Freezer Status
- количество пакетов
- категории хранения
- предупреждения

### Next Preparation Day
- дата
- прогресс подготовки
- список задач

## User Flow

Открыть приложение → увидеть что готовить → достать пакет → приготовить → обновить остаток.
