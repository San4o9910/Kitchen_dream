# Kitchen Dream Dashboard UI

## Main Screen

Sections:

1. Today meal
- Current lunch/dinner
- Required freezer item
- Cooking time

2. Freezer status
- Total packages
- Categories
- Low stock warnings

3. Preparation countdown
- Next preparation day
- Checklist progress

4. Quick actions
- Open recipes
- Add freezer item
- Start preparation batch

Visual direction:
- warm minimal kitchen style
- large cards
- simple icons
- mobile first
