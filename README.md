# 🍳 Kitchen Dream

**Kitchen Dream** — мобильное PWA-приложение для семьи из двух человек: месячное меню, проверенные рецепты, один день большой заготовки, вакуумные пакеты и учёт морозильника.

## Что уже работает

- 🏠 Главный экран с сегодняшним обедом или ужином
- ❄️ Учёт пакетов в морозильнике: списание, пополнение, фильтры и поиск
- 📅 Меню на 30 дней: обеды и ужины без завтраков
- 📖 20 подробных рецептов, адаптированных из высоко оценённых кулинарных книг
- 📸 Реальные фотографии ключевых этапов готовки с открытыми лицензиями и атрибуцией
- 🌡️ Температура безопасной готовности для мяса, птицы, фарша и рыбы
- 🧩 Кулинарный конструктор по доступным запасам и времени готовки
- 📦 Чек-лист одного большого дня заготовки
- 🛒 Пересчитанный список покупок на месяц
- 💾 Локальное сохранение всех отметок и остатков в браузере
- 📱 Адаптивный интерфейс для телефона, планшета и компьютера
- 📴 Service Worker: приложение и просмотренные фото доступны без постоянного интернета

## Рецепты и источники

Рецепты являются самостоятельными адаптациями, а не дословными копиями книг. В каждой карточке указаны:

- основная кулинарная книга и автор;
- актуальный рейтинг Goodreads с датой проверки;
- дополнительная книга, использованная для техники;
- что приготовить в большой день заготовки;
- что добавить свежим;
- пошаговое приготовление;
- безопасная температура;
- автор и лицензия каждого фото.

Полный реестр находится в [`docs/RECIPE_SOURCES.md`](docs/RECIPE_SOURCES.md).

## Важное правило хранения

Вакуумирование не заменяет холод. Сырые мясные, рыбные и фаршевые заготовки на месяц должны храниться в морозильнике. Холодильник используется для короткого хранения и безопасной разморозки пакета перед приготовлением.

## Запуск локально

```bash
cd app
npm install
npm run dev
```

Проверка рецептов, интерфейсных действий и синтаксиса:

```bash
cd app
npm run check
```

Production-сборка:

```bash
cd app
npm install
npm run build
npm run preview
```

## Публикация через GitHub Pages

Workflow находится в `.github/workflows/deploy-pages.yml`.

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В поле **Source** выберите **GitHub Actions**.
4. Перейдите в **Actions → Deploy Kitchen Dream to GitHub Pages**.
5. Нажмите **Run workflow → Run workflow**.
6. После успешного завершения приложение будет доступно по адресу:

`https://san4o9910.github.io/Kitchen_dream/`

Все последующие изменения в ветке `main` публикуются автоматически.

## Установка на телефон

### iPhone

Откройте опубликованную ссылку в Safari → **Поделиться** → **На экран «Домой»**.

### Android

Откройте ссылку в Chrome → **Установить приложение** или **Добавить на главный экран**.
